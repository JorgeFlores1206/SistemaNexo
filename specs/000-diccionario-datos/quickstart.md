# Quickstart: Verify Inventory Product Name Columns

## Prerequisites

- Open `PrototipoWeb/inventario.html` in a current desktop or mobile browser.

## Verification

1. Open the **Inventario** page and inspect a row with a product code and name.
2. Confirm **Artículo** shows only the code.
3. Confirm **Descripción del artículo** shows the product name, not the longer sample description.
4. Search for the product name and confirm the row is still found.
5. Sort by **Artículo** and **Descripción del artículo** and confirm sorting still works.
6. Open the product details and confirm the code, name, and existing long description remain available.

## Expected outcome

The code appears once in its column; the name appears once in the description column. No other
column, filtering behavior, or row action changes.
